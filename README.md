# Dungeon Master Companion

An AI-powered companion for tabletop RPG Dungeon Masters. It lets them quickly generate, organize, and run worlds, countries, towns, businesses, NPCs, dungeons, and encounters, with economies, maps, and a built-in combat tracker.
